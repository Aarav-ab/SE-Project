# Week 2: Implementing UI Designs Using React and TypeScript

## Objective

To begin converting the approved UI designs into actual frontend pages for the Citizen Portal.

## Relevant Context

After completing the initial design discussions, the next step was to implement the designs using React.js and TypeScript. The objective was to reproduce the intended layouts while keeping the code organised and maintainable.

## Work Done

- Set up and began working on the Citizen Portal frontend pages.
- Started translating the designs prepared using Stitch and Figma into React components.
- Worked with TSX files to structure page content and interactive elements.
- Used CSS to implement layouts, spacing, colours, typography, and other visual properties.
- Compared the implemented pages with the intended designs and identified areas requiring correction.

## Key Observation

The initial implementations did not always match the intended designs. Some layouts, spacing, alignments, and visual elements required repeated adjustments. Translating a visual design into reusable React components also required attention to component structure and CSS behaviour.

## Solution and Improvements

- Reviewed the differences between the implemented pages and the design references.
- Modified component structures and styling where required.
- Iteratively refined the pages to improve their visual consistency with the intended designs.

## Outcome

Initial frontend pages were created, and the process of converting the designs into working React components was established. Some pages and styling details remained incomplete.
