# Week 1: Designing the User Interface of the Smart City App

## Objective

To collaboratively plan the layout, appearance, and navigation of the different pages of the Smart City App before beginning frontend development.

## Relevant Context

The Smart City App aims to provide citizens with a platform to submit civic complaints and track their progress. Before implementation, the team needed to establish a consistent user interface and decide how the main pages would be organised.

## Work Done

- Discussed the overall appearance and structure of the application with the group.
- Identified the main pages and features required for the Citizen Portal.
- Used **Stitch** to explore and generate initial UI design ideas.
- Used **Figma** to review, organise, and refine the proposed page designs.
- Discussed page layouts, navigation elements, forms, buttons, and complaint information displays.
- Coordinated with other group members to maintain consistency across the application's pages.

## Key Observation

Designing the pages before coding helped establish a common visual direction. However, converting design concepts into a working application would require additional decisions about component structure, styling, and implementation.

## Outcome

The group established the initial UI design direction and planned the page layouts to guide the upcoming frontend development.
